# Claude Code JSONL log format — observed field inventory

Claude Code's log files are an internal format. Anthropic does not publish a
schema for them, and they change between releases. This document is therefore
not a specification: it is an **inventory of what was actually present in a
real corpus of logs**, generated by `agentlog schema`.

Treat it as a starting point for writing a parser, and re-generate it against
your own logs before relying on any particular field.

## Provenance

| | |
|---|---|
| Generated | 2026-09-05 |
| Claude Code version | 2.1.261 |
| Corpus | 6 non-interactive stream logs + 14 session transcripts from a single machine |
| Command | `agentlog schema ~/.claude/projects/ path/to/stream-logs/` |

A single-machine corpus is a real limitation. Fields tied to features this
machine never used — subagents/sidechains, MCP servers, web search, images —
are absent here because they never occurred, not because they do not exist.
Notably **no record in this corpus had `isSidechain: true`**, so nothing below
describes how subagent output is actually laid out.

## How to read it

* Each section is one **log shape**. `stream` is the output of
  `claude -p --output-format stream-json --verbose`; `session` is the
  transcript Claude Code writes under `~/.claude/projects/<slug>/<id>.jsonl`.
  They share record types but are not the same format, so they are never
  merged.
* Record types are grouped by `type`, refined by `subtype` where one exists
  (`system/init`, `system/thinking_tokens`, ...), and ordered by frequency.
* `×N` is how many records of that type were seen.
* Objects flatten with `.`; list elements collapse into a single `[]` path.
* A bare type means the field was in **every** record of that type. `12/97`
  means it was present in 12 of 97 — i.e. the field is optional.
* Trailing values are observed values, shown only where a field looks like an
  enumeration. `(varies)` means the field carried more distinct values than an
  enumeration plausibly would, and is data rather than structure. Free-form
  content, paths, URLs and addresses are never printed.
